# Reservation Widget SaaS

A modular, embeddable, multi-industry reservation platform—easy to include on any website.

---

## Overview

This project aims to build a secure, efficient, and easy-to-integrate widget for handling reservations for restaurants, trains, hotels, hairdressers, and more. It is designed for maximum flexibility and rapid onboarding for new clients.

## Key Directories
See `/docs/04_project_directory_layout.md` for structure reference.

| Directory           | Purpose                                      |
|---------------------|----------------------------------------------|
| `/frontend-widget`  | Embeddable widget source code (React/JS)     |
| `/backend-api`      | Backend business logic and API               |
| `/admin-portal`     | Admin/client dashboard (Phase 2)             |
| `/utils`            | Shared utilities and helpers                 |
| `/scripts`          | Automation and deployment scripts            |
| `/tests`            | All automated testing                        |
| `/docs`             | Architecture, features, roadmap, references  |

## Getting Started

1. Clone the repository.
2. Install dependencies using the README in each relevant subfolder.
3. See `/docs/03_implementation_roadmap.md` for current status & progression steps.
