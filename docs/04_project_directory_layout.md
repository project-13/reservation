# Project Directory Layout

A reference for how the project directory is structured for the Reservation Widget SaaS.

```
/docs                  # Documentation, architecture, roadmap, features
/frontend-widget/      # All code related to the client-embedded widget
  /src/
/backend-api/          # Backend API server
  /src/
/admin-portal/         # Admin portal for clients (phase 2)
/utils/                # Shared utility modules (validation, logging, mail, etc)
/scripts/              # Deployment, automation, and test scripts
/tests/                # Automated tests (unit/integration)
README.md              # Project-wide overview and getting started
```
